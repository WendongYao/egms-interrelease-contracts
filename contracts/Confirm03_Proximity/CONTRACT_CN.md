## 2. A 部分：阈值邻近与流失基线（T5 判读，T10 只报告）

对 release A 中的移动点（|v_A| ≥ T），记距离 d = |v_A| − T，差值幅度 a = |Δv|（随变体而定）。流失：|v_B| < T。

- **A-1 距离分层**：d 分为 [0, 0.5)、[0.5, 1)、[1, 2)、[2, 5)、≥ 5 mm/yr。报告每层的合并流失率、移动点数、占全部流失的比例。
- **A-2 随机符号基线 N1**：保留每点自己的 |Δv|，符号随机。期望流失 E1 = 0.5 · 1(| |v_A| − a | < T)。L1 = 移动点上 E1 的均值；ρ1 = L_obs / L1。
- **A-3 典型点基线 N2**：同一瓦片内 |v_A| < T/2 的点的 Δv 经验分布作为噪声 ε。E2 = P(|v_A + ε| < T)，按排序加二分查找精确计算。L2、ρ2 = L_obs / L2。
- **A-4 反方向**：以 release B 的移动点为对象，同样计算"获得"方向的 L_obs、L1、ρ1（B→A 的流失）。
- 置信区间：瓦片自助抽样 1,000 次，种子 20261120，比值取合并分子分母后相除。

**预期（判读，T5，O 用 C0，O′ 与 N′ 用 C1，发布值）：**
- **H1 邻近集中**：三个集合中，d < 1 的流失占全部流失的比例都 ≥ 0.50；且 [0, 0.5) 层流失率 ≥ 3 × [2, 5) 层流失率。
- **H2 超出随机符号**：三个集合的 ρ1（流失方向）与 ρ1（获得方向）都 > 1，且 95% 下界 > 1。含义：阈值选择本身造成回归均值，两个方向都比"只看差值幅度"预期的多。若两方向的 ρ1 区间都含 [0.8, 1.25] 内的 1，记"与随机符号一致"；若只有一个方向 > 1，记"有方向性"。
- **H3 移动点差值更大**：三个集合的 ρ2 ≥ 1.5，且 95% 下界 > 1。
- 只报告：各集合 C0 与公共窗口的同组读数；T10 的全部读数。

## 3. B 部分：GNSS 偏移分解（站点级，公共窗口站点速度，与 F8 同一定义）

- **B-1 中位数为何不相加（全点，瓦片级，只报告）**：O′、N′ 上逐瓦片求 median(Δv)、median(Δg)、median(Δv − Δg)（发布值）。报告三者跨瓦片的中位数、|median(Δv − Δg)| ≤ 0.1 的瓦片比例、median(Δv) 对 median(Δg) 的 Theil–Sen 斜率，以及落在 0.1 格点上的比例。用于解释 +0.70 与 S0 = +0.50、S1 = 0 的关系。
- **B-2 逐版偏移**：每版单独 c_r = median_s(v_r,s − v_GNSS,s)。P1 得 c(2019–23)、c(2020–24 | P1)；P2 得 c(2020–24 | P2)、c(2020–25)、c(2020–25, C1) = median_s(v_B,s − Δg_s − v_GNSS,s)。同时报告站点 Δg_s 的中位数。区间：站点自助抽样 1,000 次，种子 20261121。
  - **H4 框架位移在 GNSS 上可见（O′、N′ 都要满足）**：c(2020–25) − c(2020–24 | P2) 与 median_s Δg_s 之差 |·| ≤ 0.20 mm/yr，且其 95% 区间含 0；同时 |c(2020–25, C1) − c(2020–24 | P2)| ≤ 0.20。
  - **H5 同框架对照（P1）**：|c(2020–24 | P1) − c(2019–23)| ≤ 0.20。
  - **H6 同一版本跨版本对**：在 O 与 O′ 的共同站点上，|c(2020–24 | P1) − c(2020–24 | P2)| ≤ 0.20。
  - 只报告：c(2020–25, C1) 作为"非框架偏移"（按 §0 第 6 条，此时 EGMS 与 IGS20 的垂直框架一致）；P1 的 −1.16 按"框架（−median Δg_s）+ 非框架"做的算术分解。
- **B-3 决策层面的 R（只报告）**：在站点上，T0、T0.5 类别。R_dec = P(类_A ≠ 类_B) / mean(P(类_A ≠ 类_GNSS), P(类_B ≠ 类_GNSS))，EGMS 先减公共偏移 c（同 F8）。P2 用 C1；同时报告 C0 与 P1。区间同 B-2。
