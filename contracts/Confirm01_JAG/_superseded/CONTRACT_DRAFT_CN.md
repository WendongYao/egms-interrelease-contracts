## 1. 问题

- **第一部分（复现）**：Probe_RelCons01、Probe_EGMSUnc01、Probe_RealCF01 中写进论文的发现 F1–F11，在从未接触过的新瓦片上是否复现。
- **第二部分（A，管理判断的稳定性）**：用户用速度门限做的判断——哪里在动、哪些热点、多少建成区和人口受影响——在相邻两版之间有多大比例发生变化；其中多少来自重处理本身（公共窗口），多少来自两版窗口不同（按发布值）。
- **第三部分（B，归因）**：版本间速度差的地区差异主要随冬季缺测长度变化，还是随有效历元数变化。

边界：不做预测、基准、选择性预测；不给两个版本排名；不使用 DeformCLIP、RiskBench、EGMS-DeformBench 的代码或标签，只读与它们共用的公开原始瓦片。

## 3. 定义（沿用的部分以原代码为准）

- 公共窗口 W、速度主估计（截距 + 趋势 + 年周期）、Δv、瓦片统计量 m（250 个抽样点 |Δv| 的中位数）、密度类（n ≥ 200 密集，≤ 130 稀疏，其余中间）、派生类别、白噪声形式误差、站点处速度、公共偏移 c、站点误差：全部同 Probe_RelCons01 §3 与 Probe_EGMSUnc01，复用 `rc_common.py`、`s52_extract.py`、`s54_analysis.py`、`s72_model.py`，只改路径；改动以 diff 形式随结果公开。
- **冻结参数**（在 O 集上计算，写入 `FROZEN_PARAMS.json` 并记录哈希，之后才可抽取 N 集）：
  - B0：每个密度类一个系数 k_c，使 O 集该类 |Δv| ≤ 2·k_c·σ_formal 的比例为 95%；
  - B1：同法，以产品自带 `mean_velocity_std` 代替 σ_formal。
- **全瓦片处理**（第二、三部分）：瓦片内全部坐标匹配点，不抽样。
- **两种速度**：
  - 按发布值：各版 CSV 的 `mean_velocity` 列（各自五年窗口）；
  - 公共窗口：在 W 内用主估计重新拟合。
- **筛查状态**（每种速度、每一版各算一次）：
  - T5：|v| ≥ 5 mm/yr 为"在动"；T10：|v| ≥ 10 mm/yr 为"在动"；
  - T0：v < 0 为"沉降"；
  - T0.5：三类，v < −0.5、|v| ≤ 0.5、v > 0.5。
  - 依据：±5 mm/yr 见 EGMS 上的 ADAfinder 应用（Palamà 等 JISDM 2025）与意大利全国聚类（Becattini 等）；±10 mm/yr 见后者；0 与 ±0.5 mm/yr 见 Chen 等 2026。文献门限多用于视线向产品，此处用于 Ortho 垂直分量，在论文中说明。
- **热点**：T5、T10 下"在动"的 100 m 格网点，按 8 邻接聚类，少于 5 个点的簇丢弃（ADAfinder 的"每个活跃形变区至少 5 个测点"）。8 邻接是本文对 100 m 格网的适配。
- **暴露权重**：每个测点取其坐标所在 GHSL 100 m 像元的建成区面积（m²）与人口；最近像元，不插值。

## 4. 读法与门限（运行前写定）

### 第一部分：复现（只用 N 集）

| 编号 | 读法 | 复现标准 |
|---|---|---|
| F1 | 趋势方向与阶跃有无的翻转率（合并） | 趋势在 [8%, 20%]，阶跃在 [15%, 35%] |
| F2 | 瓦片级 Spearman ρ(n, m)；稀疏 ÷ 密集 | ρ ≤ −0.5 且 bootstrap 95% 上界 < −0.2；比值 ≥ 3（两类各 ≥ 10 个瓦片时才判此项） |
| F3 | 各密度类 \|Δv\| > 2σ_formal 的比例（瓦片中位） | 每一类 ≥ 0.5 |
| F4 | 用冻结的 k_c 计算 2σ 覆盖率 | 合并在 [0.92, 0.97]；每个瓦片数 ≥ 5 的类 ≥ 0.88 |
| F5 | `mean_velocity_std` 的不同取值数（0.1 取整）；B1 与 B0 的区间得分；瓦片内三分位比 | 取值 ≤ 20；B1 ≥ 1.10 × B0；B1 的三分位比 < B0 的 |
| F6 | 短程（同一站点簇内点对）÷ 长程（> 20 km）的速度差之差中位数 | ≤ 0.8，且 bootstrap 上界 < 1.0 |
| F7 | 站点处 \|Δv_s\| 与 GNSS 误差 e_s 的 Spearman | ρ ≥ 0.10 且第 5 百分位 > 0；站点 < 60 或稀疏区站点 < 15 时记"无法检验" |
| F8 | R = 站点 \|Δv_s\| 中位 ÷ e_s 中位 | 不设通过线；点估计 < 0.5 记为"限制复现" |
| F9–F11 | 哪一版更接近 GNSS 的符号检验；公共偏移按带分列；翻转率按类分列 | 只报告 |

不复现的发现：从论文中删除或降为"仅在原样本中观察到"，不调整标准。

### 第二部分：管理判断的稳定性（O 集与 N 集分别计算）

- **A1 点级不一致率**：两版状态不同的测点比例；按 T5、T10、T0、T0.5，两种速度，合并及按纬度带、密度类分列。另报告条件比例：A 版"在动"者中 B 版不再"在动"的比例，及反向。
- **A2 热点保留率**（T5、T10）：A 版热点中与任一 B 版热点至少共享 1 个格点的比例，及反向；匹配热点的 IoU 中位数。
- **A3 暴露加权不一致**：状态不同的测点所占建成区面积、人口，占"任一版被判为在动（或沉降）"的总量之比。
- **A4 稳定曲线**：T 从 0 到 15 mm/yr、步长 0.5 的点级不一致率（只作图）。
- **判读**：每个数字只有在 O 集与 N 集一致时才写成结论。一致指绝对差 ≤ 5 个百分点，或两者之比在 [2/3, 3/2] 内；否则写成"随样本变化"并给出两个值。事先写定的方向性预期只有一条，作为检验：公共窗口的 A1 低于按发布值的 A1（T5、T10 下，两集都成立才算成立）。

### 第三部分：归因（N 集为主，O 集对照）

- 瓦片协变量：G = 公共窗口内相邻两个历元之间的最长间隔（天，两版取较大者）；n；平均北向坐标；测点高程中位数。
- **B1 偏相关**：在 N 集瓦片上，ρ(m, G | n) 与 ρ(m, n | G)（对秩做线性回归后取残差的相关；bootstrap 1,000 次，种子 20261117）。
  - "冬季缺测为主"：|ρ(m, G | n)| ≥ 0.3 且区间不含 0，同时 ρ(m, n | G) 的区间含 0；
  - "采样次数为主"：反之；
  - 其余：未定。
- **B2 抽稀**：对 N 集每个密集瓦片，按固定种子随机指定一个稀疏或高山瓦片作为供体；两版都只保留与供体某个观测日期相差 ≤ 3 天的历元，重算 m。
  - 采样份额 S = log(m_抽稀 ÷ m_原始 的瓦片中位) ÷ log(稀疏类 m 中位 ÷ 密集类 m 中位)；
  - S ≤ 0.25 且上界 < 0.5：采样只解释小部分；S ≥ 0.5：采样是主要因素；其余：未定。
- **B3 差值结构**：去趋势、去年周期后，两版差值序列一阶自相关的中位数 ≥ 0.4，记为"低频斜坡"成立；残差相关密集类减稀疏类 ≥ 0.15，记为成立。
- 只做描述与事先写定的比较，不建预测模型。
