## 第二部分：管理判断的稳定性（O、O′、N′ 三组）

主读数为瓦片中位数；A3 为全部瓦片的加总比。完整表见 results/part2__agreement.csv。

**三组一致、可以写成结论的读数：**
- **T5 / T10 下的点级不一致率很小：** 瓦片中位数 T5 约 1–2%，T10 约 0.1–0.2%。原因是绝大多数测点本来就不在动。
- **被判为"在动"的点里，换一版就有相当一部分不再在动：**
  - T10 下的流失率为 0.39–0.56（"按发布值"和"公共窗口"两种速度都在三组间一致）；
  - 新增率为 0.38–0.48（T5、T10，两种速度）。
- **热点：**
  - T10 下 A 版热点保留率 0.76–0.84，B 版热点保留率 0.77–1.00；
  - 匹配热点的 IoU 中位数 0.70–0.82（T5、T10，两种速度）。
- **暴露：**
  - T5：建成区加权的不一致比例 0.20–0.27，即"任一版判为在动"的建成区里约四分之一只在一版里被判为在动（两种速度）；
  - T10："按发布值"下为 0.40–0.60。

**三组不一致、只能写成"随版本对或瓦片变化"的读数：**
- T5 的流失率：0.35 / 0.47–0.49 / 0.57–0.62，T5 的 A 版热点保留率：0.81 / 0.75–0.79 / 0.50–0.52（依次为 O、O′、N′）。
- T0 与 T0.5（沿海研究常用的稳定带）：P2 的不一致明显更大。T0.5 点级不一致 0.15–0.18 / 0.23–0.25 / 0.35–0.36；建成区加权 0.23–0.26 / 0.38–0.41 / 0.48–0.51。
- 人口加权的 T5、T10 部分不一致。

**方向性预期（公共窗口的不一致低于按发布值）：** T10 在三组都成立；T5 在 O′、N′ 不成立（差异在千分位）。按合同只对 T10 写成成立。

## 第三部分：归因（N′ 为主，O′ 对照）

| 读法 | N′ | O′ |
|---|---|---|
| B1 偏相关 | ρ(m, G \| n) = 0.26 [0.01, 0.49]；ρ(m, n \| G) = −0.18 [−0.43, 0.09] → **未定**（未达 0.3） | 0.41 [0.25, 0.54]；−0.02 [−0.17, 0.14] → **冬季缺测为主** |
| B2 抽稀 | S = 0.034 [0.017, 0.052]，55 个密集瓦片 → **采样只解释小部分** | S = 0.039 [0.020, 0.064] → 采样只解释小部分 |
| B3 低频斜坡 | 一阶自相关中位 0.67 → **成立** | 0.68 → 成立 |
| B3 残差相关差 | 密集 − 稀疏 = 0.20 → 成立 | 0.12 → 不成立 |

**读法：**
- **抽稀实验很干净：** 把密集瓦片抽稀到稀疏或高山瓦片的观测日历，版本差只上升约 3%（中位比 1.03），只占"稀疏比密集大约 2.6 倍"的约 4%。差异大不是因为观测次数少。
- **冬季缺测：** 在旧瓦片上是主因，在新瓦片上方向相同但未达门限。新瓦片里冬季缺测与历元数高度相关（ρ = −0.86），只有 8 个稀疏瓦片，可分辨力有限。
- 测点高程在 2020–2024 版文件中缺失，相关项无法计算。这一项不是合同的判读项。

## 对论文的含义（供讨论，本文件不做决定）

1. **稳的结论：**
   - 版本间速度差普遍超过形式误差（F3）；
   - 产品自带标准差几乎不含逐点信息（F5）；
   - 差异短距离相关（F6）；
   - 差异大小随地区系统变化（F2 的秩相关）；
   - 差异是逐点的低频斜坡，且不是观测次数少造成的（B2、B3）；
   - 被判为"在动"的点和建成区，有相当比例在下一版被翻转（第二部分三组一致的读数）。
2. **只在 P1 上成立的：** 具体的翻转率区间（F1）、放大系数 9/17/45（F4）、与 GNSS 同向（F7）。论文里必须注明只在 2019–2023 对 2020–2024 上观察到；在新一对版本上，密集区差异变大，系数需要上调。
3. **需要改写的限制：** 原来"版本差异只占对 GNSS 误差的 38%"（H2 失败）在 P2 上变成约 100%。论文不能再写"版本差异不是误差主体"，而应写成"这一比例随版本对在约 0.4 到 1.0 之间变化"。
4. **第二部分最有用户价值的数字：** 一旦用门限筛查，被判为"在动"的点和面积，约有四到六成在下一版换了判断；整片热点（T10）的保留率在八成左右。
